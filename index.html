Приложение инспектора

Mobile · UX/UI · User Flow

Мобильный интерфейс для проведения проверок, фиксации замечаний и коммуникации по объекту.

Project Overview

Приложение инспектора — мобильный интерфейс для проведения проверок, фиксации замечаний и коммуникации по объекту. Проект сфокусирован на полевом сценарии работы: пользователь должен быстро открыть задачу, изучить детали, зафиксировать проблему, прикрепить фотографии и продолжить обсуждение внутри приложения.

Приложение построено на базе существующей ERP-системы, которая изначально работала только на десктопе. Моя задача — взять заложенную в ней логику продукта и на её основе спроектировать мобильное приложение под конкретный кейс заказчика.

Product Goal

Создать понятный и быстрый мобильный инструмент для инспектора, который помогает работать с проверками на месте: просматривать задачи, переходить в карточки, фиксировать результаты, добавлять визуальные материалы и отслеживать дальнейшую коммуникацию по замечаниям.

Design Task

Воплотить сценарий инспекции в мобильном интерфейсе. Сделать работу быстрой, а информацию - легко считываемой. Объединить в одном приложении несколько процессов: работу с задачами, фотофиксацию, просмотр деталей и коммуникацию.

Key Scenarios

Работа с задачей

Инспектор открывает список задач, выбирает проверку и переходит в карточку с деталями, статусом и связанной информацией.

Фиксация замечания

Из карточки пользователь добавляет замечание, вносит информацию по результату проверки и сохраняет её в контексте задачи.

Фотофиксация

Пользователь прикладывает изображения через камеру или галерею, чтобы зафиксировать проблему визуально в момент осмотра.

Коммуникация

После фиксации замечания пользователь продолжает обсуждение внутри интерфейса, используя комментарии или чат.

UX Decisions

  • Быстрый доступ к действиям — основные действия доступны без длинных переходов и лишних уровней навигации
  • Понятная структура экранов — каждый экран решает конкретную задачу: просмотр, фиксация, вложения или коммуникация
  • Поддержка полевого сценария — интерфейс для использования в движении: читаемость, простая иерархия, короткие действия
  • Связь задачи и обсуждения — коммуникация встроена в рабочий процесс, не существует отдельно от контекста
  • Фото как часть процесса — добавление изображений не вторичная функция, а ключевой элемент фиксации результата

Outcome

Мобильный интерфейс, объединяющий несколько рабочих процессов инспектора в одном сценарии: просмотр задач, переход в карточку, фиксацию замечаний, добавление фотографий и дальнейшую коммуникацию по объекту. Проект показывает работу не только с визуальной частью, но и с логикой взаимодействия, последовательностью действий и организацией мобильного рабочего процесса.

Обложка проекта

Мобильный конструктор условий

Mobile · UX/UI · Logic Builder

Мобильный интерфейс для создания и настройки логических условий и правил в рамках продуктовой системы.

О проекте

Проект мобильного интерфейса для конструирования логических условий. Пользователь создаёт правила и условия через визуальный интерфейс, без необходимости писать код.

Общий вид приложения

Задача

Спроектировать понятный мобильный интерфейс для создания сложных логических конструкций. Сделать процесс настройки условий интуитивным и доступным для пользователей без технического бэкграунда.

Моя роль

  • Проработал структуру экранов конструктора
  • Собрал логику добавления и редактирования условий
  • Спроектировал визуальный язык блоков и связей
  • Оформил финальный UI

Решение

Интерфейс построен на принципе визуальных блоков: каждое условие — отдельный элемент, который можно добавить, изменить или удалить. Логические операторы (И, ИЛИ) связывают блоки в единую структуру. Навигация между уровнями вложенности реализована через переходы между экранами.

Ключевые экраны

Результат

Получился мобильный конструктор, в котором пользователь может последовательно создавать и редактировать логические условия без перегруженного интерфейса. Структура экранов поддерживает как простые, так и вложенные сценарии.

Обложка проекта

Дизайн-система «Helios 3»

Design System · UI-kit · Components

Компонентная дизайн-система: типографика, цвета, UI-элементы, паттерны взаимодействия и правила использования.

О проекте

Дизайн-система «Helios 3» — набор компонентов, правил и паттернов для обеспечения визуальной целостности продуктов. Система покрывает типографику, цветовую палитру, UI-элементы и их состояния.

Обзор системы

Задача

Создать единую систему компонентов, которая обеспечит консистентность интерфейсов, ускорит разработку новых экранов и упростит передачу макетов в разработку.

Моя роль

  • Определил набор базовых компонентов
  • Разработал цветовую палитру и типографическую шкалу
  • Собрал UI-kit с состояниями элементов
  • Описал правила использования компонентов

Состав системы

Типографика

Иерархия заголовков, основной текст, вспомогательные стили, размеры и межстрочные интервалы.

Цветовая палитра

Основные, акцентные, семантические и нейтральные цвета с вариантами для светлой и тёмной тем.

Компоненты

Кнопки, поля ввода, карточки, навигация, модальные окна, тосты, чекбоксы, радиокнопки.

Паттерны

Формы, списки, таблицы, дашборды — типовые layouts и правила их построения.

UI-kit и компоненты

Результат

Система компонентов, которая обеспечивает визуальную целостность продуктов, ускоряет создание новых экранов и упрощает коммуникацию между дизайном и разработкой.

Обложка проекта

Inderoom

Web · UI/UX · Catalog

Веб-интерфейс для просмотра и выбора интерьерных решений с акцентом на визуальную подачу и навигацию.

О проекте

Веб-проект с визуально насыщенной подачей контента. Интерфейс для просмотра, выбора и сравнения интерьерных решений с акцентом на визуальную подачу и удобную навигацию.

Главная страница

Задача

Организовать контент так, чтобы пользователю было удобно просматривать подборки, переходить между категориями и быстро находить нужные решения без перегруженного интерфейса.

Моя роль

  • Проработал структуру страниц
  • Выстроил логику каталога и карточек
  • Работал с визуальной иерархией
  • Оформил ключевые UI-блоки

Решение

Фокус на визуальной подаче контента, структуре карточек, читаемой композиции страниц и удобной навигации между разделами. Интерфейс достаточно нейтральный, чтобы акцент оставался на контенте, но при этом целостный и современный по визуальному языку.

Каталог и карточки

Результат

Интерфейс, в котором визуальный контент подан аккуратно и системно, а сценарий просмотра и выбора выглядит понятным и последовательным.
